বাংলাদেশের সীমান্ত অতিক্রম করা প্রতিটি পণ্যের একটি HS code দরকার — আর ভুল HS code এক্সপোর্ট কারখানায় আমি দেখা কাস্টমস বিলম্ব, অতিরিক্ত ডিউটি অ্যাসেসমেন্ট, আর ব্যর্থ বন্ডেড ওয়্যারহাউস রিকনসিলিয়েশনের সবচেয়ে সাধারণ কারণগুলোর একটি। চট্টগ্রাম বন্দরে কাস্টমস অফিসাররা একটি শিপমেন্ট আটকে দেবেন যদি এক্সপোর্ট ডিক্লারেশনের HS code পণ্যের ফিজিক্যাল বর্ণনার সাথে না মেলে।

Odoo-ই সেই জায়গা যেখানে সঠিক HS code শৃঙ্খলা প্রয়োগ করা যায়। কোডটি প্রোডাক্ট রেকর্ডে থাকলে, এটি স্বয়ংক্রিয়ভাবে প্রতিটি সেলস অর্ডার, ডেলিভারি, কমার্শিয়াল ইনভয়েস, আর প্যাকিং লিস্টে প্রবাহিত হয়। এই গাইড বাংলাদেশি এক্সপোর্টারদের জন্য সম্পূর্ণ সেটআপ কভার করে।

ভুল HS code শুধু কাস্টমস বিলম্ব তৈরি করে না। এটি এমন ডিউটি দায় তৈরি করে যা অডিটররা বছর পরেও উদ্ধার করতে পারেন।

বাংলাদেশে HS code সিস্টেম

Harmonized System (HS) হলো ট্রেড করা পণ্য শ্রেণিবদ্ধ করার একটি আন্তর্জাতিক স্ট্যান্ডার্ড। বাংলাদেশ ৮-সংখ্যার HS code ব্যবহার করে — স্ট্যান্ডার্ড আন্তর্জাতিক ৬-সংখ্যার HS code প্লাস বাংলাদেশ কাস্টমস দ্বারা সংজ্ঞায়িত ২টি দেশ-নির্দিষ্ট সংখ্যা।

61
Chapter
বিস্তৃত প্রোডাক্ট ক্যাটাগরি (যেমন, নিট গার্মেন্ট)
09
Heading
চ্যাপ্টারের মধ্যে প্রোডাক্ট গ্রুপ (যেমন, T-shirt)
10
Subheading
মেটেরিয়াল বা কনস্ট্রাকশন (যেমন, কটনের তৈরি)
10
BD digits
বাংলাদেশ-নির্দিষ্ট আরও বিভাজন

প্রথম ৬টি সংখ্যা (61.09.10) আন্তর্জাতিক আর সব WCO সদস্য দেশে সামঞ্জস্যপূর্ণ। শেষ ২টি সংখ্যা (এই উদাহরণে 10) বাংলাদেশ-নির্দিষ্ট আর NBR-এর প্রকাশিত বাংলাদেশ কাস্টমস ট্যারিফ শিডিউল দ্বারা নির্ধারিত। বাংলাদেশের জন্য সবসময় ৮-সংখ্যার কোড ব্যবহার করুন — একটি আন্তর্জাতিক সোর্স থেকে ৬-সংখ্যার HS code বাংলাদেশ ট্যারিফে হুবহু নাও মিলতে পারে।

বাংলাদেশ কাস্টমস ট্যারিফ NBR ওয়েবসাইটে পাওয়া যায় আর নিয়মিত আপডেট হয়। Odoo-তে এন্টার করার আগে আপনার C&F (Clearing and Forwarding) এজেন্টের সাথে বর্তমান ৮-সংখ্যার কোড নিশ্চিত করুন — তারা প্রতিদিন কাস্টমসের সাথে ডিল করেন আর আপনার নির্দিষ্ট প্রোডাক্টের ব্যবহারিক ক্লাসিফিকেশন জানেন।

গুরুত্বপূর্ণ

উপরের HS code গুলো উদাহরণমূলক। বাংলাদেশ কাস্টমস ট্যারিফ হেডিং আর সাবহেডিং নিয়মিত সংশোধিত হয়। আপনার নির্দিষ্ট প্রোডাক্টের সঠিক ৮-সংখ্যার কোড সবসময় আপনার C&F এজেন্ট বা বর্তমান NBR ট্যারিফ শিডিউলের সাথে নিশ্চিত করুন। ভুল শ্রেণিবিন্যাস — এমনকি অনিচ্ছাকৃতভাবে হলেও — ডিউটি পুনর্মূল্যায়ন, জরিমানা, আর শিপমেন্ট হোল্ডের ফল দিতে পারে।

নোট · নিটওয়্যার এক্সপোর্টার, নতুন স্টাইল প্রবর্তনচট্টগ্রামে কাস্টমস হোল্ড
একটি কারখানা একটি বিদ্যমান প্রোডাক্ট রেকর্ড ডুপ্লিকেট করে Odoo-তে একটি নতুন গার্মেন্ট স্টাইল যোগ করেছিল — আর ডুপ্লিকেটটি মূল স্টাইলের HS code বহন করে নিয়ে গিয়েছিল। দুই গার্মেন্ট ভিন্ন সাবহেডিং-এ শ্রেণিবদ্ধ ছিল। C&F এজেন্ট যে এক্সপোর্ট ডিক্লারেশন ফাইল করেছিলেন তাতে উত্তরাধিকারসূত্রে পাওয়া কোডটি ব্যবহৃত হয়েছিল; কাস্টমস ঘোষিত কোড আর ফিজিক্যাল পণ্যের মধ্যে মিসম্যাচ ফ্ল্যাগ করে, আর ডিক্লারেশন সংশোধন হওয়া পর্যন্ত কনটেইনারটি দুই দিন বন্দরে বসে থাকে। খরচটা ডিউটি ছিল না — ডেমারেজ আর বিলম্বিত জাহাজ ছিল। সমাধানটা ছিল একটি প্রোডাক্ট-ক্রিয়েশন নিয়ম: C&F এজেন্টের কাছ থেকে চ্যাটারে একটি সাইন-অফ নোট না থাকলে কোনো এক্সপোর্টেড প্রোডাক্ট Odoo-তে বিক্রয়যোগ্য চিহ্নিত হবে না। একটি প্রোডাক্ট রেকর্ড ডুপ্লিকেট করলে কখনো একটি ভেরিফায়েড কোড আসে না — এটি একটি অনুমান বহন করে আনে।

Odoo প্রোডাক্টে HS code সেট করা

প্রথমে, Odoo-তে HS code ফিল্ড চালু করুন: Settings → Inventory → Customs → "Customs" টিক করুন। এটি সব প্রোডাক্ট রেকর্ডে HS Code ফিল্ড যোগ করে।

তারপর, প্রতিটি এক্সপোর্টেড প্রোডাক্টের জন্য: Inventory → Products → [প্রোডাক্ট বেছে নিন] → General Information ট্যাব → HS Code ফিল্ড। সম্পূর্ণ ৮-সংখ্যার বাংলাদেশ HS code এন্টার করুন (যেমন, 6109101000 — কিছু সিস্টেম ডট ছাড়া পছন্দ করে, অন্যগুলো ডট ব্যবহার করে। Odoo দুটো ফরম্যাটই গ্রহণ করে)।

Odoo-তে HS code ডেটা ম্যানেজমেন্টের মূল বিষয়:

  • প্রোডাক্ট ভ্যারিয়েন্টে নয়, প্রোডাক্টে সেট করুন — রং/সাইজ ভ্যারিয়েন্ট থাকা RMG-এর জন্য, একই স্টাইলের সব ভ্যারিয়েন্টে HS code সাধারণত একই হয়। প্রোডাক্ট টেমপ্লেটে একবার সেট করুন।
  • HS গ্রুপিং-এর জন্য প্রোডাক্ট ক্যাটাগরি ব্যবহার করুন — HS চ্যাপ্টারের সাথে সামঞ্জস্যপূর্ণ প্রোডাক্ট ক্যাটাগরি তৈরি করুন (যেমন, "Knitwear — Chapter 61")। এটি বাল্ক HS code অ্যাসাইনমেন্ট সহজ করে আর HS চ্যাপ্টার অনুযায়ী রিপোর্টিং সাপোর্ট করে।
  • প্রতি কোয়ার্টারে HS code অডিট করুন — নতুন প্রোডাক্ট বা স্টাইল যোগ করলে, প্রথম শিপমেন্টের আগেই HS code সেট করতে হবে। আপনার C&F এজেন্টের HS code সাইন-অফসহ একটি প্রোডাক্ট ক্রিয়েশন চেকলিস্ট তৈরি করুন।
  • Country of Origin — প্রোডাক্টে (একই লোকেশনে) এই ফিল্ডটিও সেট করুন। BGMEA সার্টিফিকেশনের অধীনে বাংলাদেশ এক্সপোর্টের জন্য, এটি সবসময় "Bangladesh" — EU GSP আর US ডিউটি প্রেফারেন্স অ্যাপ্লিকেশনের জন্য প্রয়োজনীয়।

ইমপোর্টে কাস্টমস ডিউটির জন্য ফিসক্যাল পজিশন

বাংলাদেশি ইমপোর্টে HS code দ্বারা নির্ধারিত রেটে কাস্টমস ডিউটি প্রযোজ্য হয়। কাঁচামাল ইমপোর্ট করলে (ইয়ার্ন, ফেব্রিক, অ্যাক্সেসরিজ, সাইকেল পার্টস), Odoo-তে ল্যান্ডেড কস্ট কাস্টমস ডিউটিসহ প্রকৃত ইমপোর্ট খরচ প্রতিফলিত করা উচিত। এখানে দুটি প্রধান পরিস্থিতি আছে:

ইমপোর্ট টাইপকাস্টমস ডিউটি ট্রিটমেন্টOdoo পদ্ধতি
সাধারণ ইমপোর্ট (নন-বন্ডেড) ইমপোর্টের সময় পূর্ণ কাস্টমস ডিউটি, VAT, এবং advance income tax (AIT) প্রদেয় প্রোডাক্ট কস্টে কাস্টমস ডিউটি, VAT, আর AIT যোগ করতে Landed Costs ব্যবহার করুন। এগুলো ল্যান্ডেড কস্ট ফিচারের মাধ্যমে ইনভেন্টরি ভ্যালুয়েশনে পোস্ট হয়।
বন্ডেড ওয়্যারহাউস / EPZ ইমপোর্ট ১০০% এক্সপোর্ট প্রোডাকশনের জন্য কাঁচামালের ডিউটি-ফ্রি ইমপোর্ট। ডিউটি স্থগিত, ছাড়প্রাপ্ত নয় — প্রোডাকশনে খরচ হতে হবে আর এক্সপোর্ট প্রমাণিত করতে হবে। একটি "Bonded Import — Duty Suspended" ফিসক্যাল পজিশন তৈরি করুন। এক্সপেন্স করার বদলে ইমপোর্ট ডিউটি একটি Duty Suspended লায়াবিলিটি অ্যাকাউন্টে ম্যাপ করুন। এক্সপোর্ট প্রমাণ জমা দেওয়া হলে এটি ক্লিয়ার করুন।
SRO/duty concession ইমপোর্ট নির্দিষ্ট শিল্প বা প্রোডাক্টের জন্য একটি Statutory Regulatory Order (SRO)-এর অধীনে কমানো ডিউটি রেট ছাড়ের রেটে একটি নির্দিষ্ট পারচেজ ট্যাক্স তৈরি করুন আর প্রাসঙ্গিক ভেন্ডর টাইপে একটি ফিসক্যাল পজিশন অ্যাসাইন করুন। অডিট রেফারেন্সের জন্য SRO নম্বর নথিভুক্ত করুন।
সম্পর্কিত পাঠ

কাস্টমস ডিউটির জন্য ফিসক্যাল পজিশন আপনার NBR VAT কনফিগারেশনের সাথে একসাথে কাজ করে। এখনও ট্যাক্স গ্রুপ আর আউটপুট/ইনপুট VAT অ্যাকাউন্ট সেটআপ না করে থাকলে, প্রথমে পড়ুন Odoo-র জন্য NBR VAT কমপ্লায়েন্স গাইড — সেখানকার ফিসক্যাল পজিশন ফ্রেমওয়ার্ক কাস্টমস ডিউটি ম্যাপিং-এও সমানভাবে প্রযোজ্য।

Odoo থেকে তৈরি হওয়া এক্সপোর্ট ডকুমেন্ট

একটি Sales Order কনফার্ম হলে আর পণ্য শিপড হলে, Odoo মূল এক্সপোর্ট ডকুমেন্টগুলো তৈরি করে। আপনার C&F এজেন্টের কাছে ব্যবহারযোগ্য হতে প্রতিটির জন্য সঠিক প্রোডাক্ট ডেটা — বিশেষ করে HS code — দরকার।

Odoo থেকে
Commercial Invoice
Sales → Orders → Invoice। বায়ার, সেলার, প্রোডাক্ট, কোয়ান্টিটি, ইউনিট প্রাইস, মোট মূল্য, কারেন্সি, Incoterm দেখায়। ইনভয়েস টেমপ্লেটে যোগ করা থাকলে HS code প্রিন্ট হয়।
Odoo থেকে
Packing List
Delivery Order → Print। কার্টন সংখ্যা, গ্রস/নেট ওয়েট, মাত্রা দেখায়। প্রতিটি প্রোডাক্ট রেকর্ডে প্রোডাক্ট ওয়েট (kg) সেট থাকা দরকার।
Odoo থেকে
Delivery Order
Inventory → Delivery Orders। সব লট/সিরিয়াল নম্বর, শিপড কোয়ান্টিটি ধারণ করে। গার্মেন্ট শিপমেন্ট কাউন্ট ভেরিফিকেশনের জন্য ব্যবহৃত।
বাহ্যিক (C&F এজেন্ট)
Bill of Export
আপনার C&F এজেন্ট দ্বারা NBR ASYCUDA++-এ ফাইল করা হয়। Odoo কমার্শিয়াল ইনভয়েস থেকে HS code, মূল্য, আর কোয়ান্টিটি ব্যবহার করে।
বাহ্যিক (C&F এজেন্ট)
Export General Manifest
জাহাজ লোডিং-এর সময় বাংলাদেশ কাস্টমসে জমা দেওয়া হয়। Bill of Export রেফার করে। Odoo দ্বারা তৈরি হয় না।
বাহ্যিক (BGMEA/EPB)
Certificate of Origin
BGMEA (গার্মেন্ট) বা EPB দ্বারা ইস্যু করা। EU, UK, কানাডায় GSP প্রেফারেনশিয়াল ডিউটি অ্যাক্সেসের জন্য প্রয়োজনীয়। ডেটা Odoo ইনভয়েস থেকে নেওয়া।

আপনার Odoo প্রোডাক্ট ডেটার গুণমান সরাসরি আপনার এক্সপোর্ট ডকুমেন্টের গুণমান নির্ধারণ করে। ওয়েট মিসিং একটি প্রোডাক্ট মানে একটি খালি প্যাকিং লিস্ট। HS code মিসিং মানে C&F এজেন্টকে প্রতি শিপমেন্টে আপনার কারখানায় ফোন করতে হয়। প্রথম শিপমেন্টের আগে — পরে নয় — একটি প্রোডাক্ট ডেটা কোয়ালিটি স্ট্যান্ডার্ড তৈরি করুন আর প্রয়োগ করুন।

Odoo-তে কাঁচামালে ইমপোর্ট ডিউটি হ্যান্ডেল করা

ইয়ার্ন, ফেব্রিক, অ্যাক্সেসরিজ, বা কম্পোনেন্ট ইমপোর্ট করলে, আপনার ব্যবসার প্রকৃত খরচে CIF ভ্যালুর সাথে ইমপোর্ট ডিউটি, সাপ্লিমেন্টারি ডিউটি (SD), রেগুলেটরি ডিউটি (RD), VAT, advance income tax (AIT), আর C&F চার্জ যোগ হয়। Odoo-র Landed Costs ফিচার এটি হ্যান্ডেল করে।

যান Inventory → Operations → Landed Costs → New-তে:

  1. পারচেজ রিসিপ্ট লিংক করুন — ইমপোর্টেড পণ্য গ্রহণ করা ইনকামিং শিপমেন্ট সেলেক্ট করুন
  2. কস্ট লাইন যোগ করুন — প্রতিটি ইমপোর্ট চার্জ টাইপের জন্য একটি লাইন:
    • Customs Duty (প্রোডাক্ট ভ্যালু অনুযায়ী — স্প্লিট মেথড: "By Current Cost")
    • Supplementary Duty (প্রযোজ্য হলে)
    • VAT on Import (নোট: এটি ইনপুট VAT হিসেবে দাবিযোগ্য হতে পারে — আপনার ট্যাক্স অ্যাডভাইজারের সাথে চেক করুন)
    • AIT — Advance Income Tax (একটি ডিডাক্টিবল ট্যাক্স ক্রেডিট, আলাদাভাবে পোস্ট করা)
    • C&F Charges (ফ্রেইট, হ্যান্ডলিং, এজেন্সি ফি)
  3. ভ্যালিডেট করুন — Odoo প্রতি প্রোডাক্ট ইউনিটে অতিরিক্ত কস্ট হিসাব করে ইনভেন্টরি ভ্যালুয়েশনে যোগ করে। আপনার কাঁচামালের কস্ট এখন প্রকৃত ল্যান্ডেড কস্ট প্রতিফলিত করে।
Sales CRM সংযোগ

সঠিক ল্যান্ডেড কস্ট প্রোডাক্ট কস্ট রিপোর্টিং-এ যোগ হয় যা শেষ পর্যন্ত আপনার এক্সপোর্ট প্রাইসিং তথ্য দেয়। আমি যখন বাংলাদেশি এক্সপোর্টারদের জন্য Odoo Sales ও CRM সেটআপ করি, শুরুর পয়েন্টটা সবসময়: আপনার প্রোডাক্ট কস্ট কি সঠিক? কাঁচামালের ল্যান্ডেড কস্ট ভুল হলে, Sales Order-এ আপনার মার্জিন বিশ্লেষণ অর্থহীন। Odoo-তে চলা যেকোনো বাংলাদেশি এক্সপোর্ট ব্যবসার জন্য HS code অ্যাকুরেসি আর ল্যান্ডেড কস্ট মৌলিক।

বন্ডেড ওয়্যারহাউস কারখানার জন্য (EPZ বা BGMEA-এর অধীনে বন্ডেড), ডিউটি ট্রিটমেন্ট ভিন্ন — বিস্তারিত কভার করা হয়েছে Odoo-র জন্য EPZ ও SEZ কমপ্লায়েন্স গাইডে। সংক্ষিপ্ত সংস্করণ: ইমপোর্ট ডিউটি স্থগিত (পরিশোধিত নয়), একটি লায়াবিলিটি হিসেবে ট্র্যাক করা হয়, আর বন্ডেড কোটা পিরিয়ডের মধ্যে এক্সপোর্ট প্রমাণ দিলে নিশ্চিহ্ন হয়ে যায়।

সচরাচর জিজ্ঞাসা

Odoo-তে প্রোডাক্টের HS code কোথায় এন্টার করব?

Settings → Inventory-এ যান → "Customs" চালু করুন। তারপর যেকোনো প্রোডাক্ট রেকর্ড খুলুন: Inventory → Products → [প্রোডাক্ট] → General Information ট্যাব → HS Code ফিল্ড। সম্পূর্ণ ৮-সংখ্যার বাংলাদেশ HS code এন্টার করুন। একবার সেট হলে, কোডটি ডেলিভারি অর্ডার, কাস্টমস রিপোর্টে পাওয়া যায়, আর আপনার কমার্শিয়াল ইনভয়েস PDF টেমপ্লেটে যোগ করা যায়। যেকোনো প্রোডাক্টের প্রথম শিপমেন্টের আগে HS code সেট করুন — পরে পরিবর্তন করলে ঐতিহাসিক ডকুমেন্ট আপডেট হয় না।

বাংলাদেশি গার্মেন্ট এক্সপোর্টাররা কোন HS code ব্যবহার করে?

RMG এক্সপোর্ট প্রধানত Chapter 61 (নিটেড গার্মেন্ট — T-shirt, পোলো শার্ট, সোয়েটশার্ট, স্পোর্টসওয়্যার) আর Chapter 62 (ওভেন গার্মেন্ট — ট্রাউজার, শার্ট, জ্যাকেট)-এর অধীনে পড়ে। নির্দিষ্ট ৮-সংখ্যার কোড নির্ভর করে মেটেরিয়াল (কটন, সিন্থেটিক, ব্লেন্ডেড), কনস্ট্রাকশন (নিটেড বনাম ওভেন), আর জেন্ডার ক্যাটাগরির ওপর। সবসময় আপনার C&F এজেন্টের সাথে নিশ্চিত করুন — তারা বর্তমান বাংলাদেশ ট্যারিফ শ্রেণিবিন্যাস চেক করতে পারেন আর প্রতিটি স্টাইলের জন্য সঠিক কোড পরামর্শ দিতে পারেন।

Odoo কি স্বয়ংক্রিয়ভাবে বাংলাদেশ কাস্টমস এক্সপোর্ট ডিক্লারেশন তৈরি করে?

না। বাংলাদেশ কাস্টমস এক্সপোর্ট ডিক্লারেশন (Bill of Export) C&F এজেন্ট দ্বারা ASYCUDA++ বা NBR ইলেকট্রনিক সিস্টেমের মাধ্যমে ফাইল করা হয় — Odoo-র মাধ্যমে নয়। Odoo কমার্শিয়াল ইনভয়েস, প্যাকিং লিস্ট, আর ডেলিভারি ডকুমেন্টেশন তৈরি করে যা C&F এজেন্ট কাস্টমস ফাইলিং-এর জন্য সোর্স ডকুমেন্ট হিসেবে ব্যবহার করেন। নিশ্চিত করুন আপনার Odoo কমার্শিয়াল ইনভয়েস প্রোডাক্ট বর্ণনা, HS code, কোয়ান্টিটি, ইউনিট প্রাইস, আর Incoterm-সহ স্পষ্টভাবে প্রিন্ট হয় — এই ফিল্ডগুলো C&F এজেন্টের দরকার।

Odoo কীভাবে ইমপোর্টেড কাঁচামালের কাস্টমস ডিউটি হ্যান্ডেল করে?

Landed Costs ফিচার ব্যবহার করুন (Inventory → Operations → Landed Costs)। ইমপোর্ট রিসিপ্ট লিংক করুন আর প্রতিটি ইমপোর্ট চার্জের জন্য কস্ট লাইন যোগ করুন: কাস্টমস ডিউটি, সাপ্লিমেন্টারি ডিউটি, ইমপোর্টে VAT, AIT, আর C&F ফি। Odoo এই কস্টগুলো ইমপোর্টেড প্রোডাক্ট জুড়ে বিতরণ করে আর ইনভেন্টরি ভ্যালুয়েশনে যোগ করে। এটি আপনাকে প্রতি ইউনিটে একটি সঠিক ল্যান্ডেড কস্ট দেয়, যা আপনার cost of goods sold আর এক্সপোর্ট সেলস অর্ডারে মার্জিন বিশ্লেষণে প্রবাহিত হয়।
