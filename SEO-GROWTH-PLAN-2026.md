# mhasan.me — 6-Month SEO & Growth Plan (Sep 2026 – Mar 2027)

Goal as stated: rank #1 for "Odoo ERP consultant Bangladesh" / "Odoo consultant Bangladesh" and hold it for 6+ months.

**Reality check first, so the rest of this plan is read correctly:** nobody — no agency, no tool, no amount of on-page work — can *guarantee* a #1 Google position. Rankings are decided by Google's algorithm, what the competition does in response, and off-site trust signals that take months to accumulate and aren't fully controllable. What this plan does is maximize the probability and durability of a top ranking by fixing every lever that's actually controllable, in priority order, with realistic timing. Treat month numbers as sequencing, not guarantees.

## 6. Technical monitoring checklist (re-run monthly)

```
# Duplicate titles/descriptions across lab/
for f in lab/*.html; do grep -o '<title>.*</title>' "$f"; done | sort | uniq -c | sort -rn | awk '$1>1'

# Robots meta anomalies (should be index,follow except testimonials)
for f in $(find . -name "*.html" -not -path "./bn/*"); do r=$(grep -o 'name="robots" content="[^"]*"' "$f"); echo "$f -> $r"; done | grep -v 'index, follow"'

# Sitemap URL count vs actual file count
grep -c '<loc>' sitemap.xml
```

## 7. KPIs to actually watch

- **Leading indicators (months 1–3)**: GBP profile views/actions, GSC impressions growth, new backlinks in Ahrefs, LinkedIn post reach
- **Lagging indicators (months 3–6)**: keyword position for "Odoo ERP consultant Bangladesh" / "Odoo consultant Bangladesh" in GSC, organic click growth, inquiry/contact-form volume attributed to organic
- Don't over-index on rank-tracking tools showing daily fluctuation — check monthly, not daily; short-term SERP volatility is normal and not actionable.
